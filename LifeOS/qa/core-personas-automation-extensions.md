# Core, personas and automation extensions — 2026-11-03

This is an **unreleased source update**, not a claim that the entire requested list has completed release acceptance. Bank SMS/email parsing was explicitly removed from scope by the user. The former generic bank-alert screen, parser service and routes have been removed; its applied migration and historical import fingerprints remain so existing databases can migrate without losing history. Expense keyword rules and normal expense entry remain.

## Data and security verification

All automated tests use disposable databases. Applied migration files were preserved. Intelligence apply/undo and receipt posting now claim previews inside their transactions; a lost claim rolls back financial effects. Approved script processes inherit the selected profile data directory. Backup checksum validation now uses the same newline normalization as the migrator, fixing valid Windows CRLF backups being rejected. Original user changes to university and launcher files were retained; concurrently appearing School/LifePlanning work was not replaced.

New service suites: `profiles_packs.php`, `capture_planning_trends.php`, `focus_intelligence.php`, `connectivity.php`. Browser coverage: `extensions_ui.py` verifies capture, future-date planning/apply/undo, trends and Sinhala/Tamil rendering at desktop/narrow widths; screenshots are retained under `tests/.tmp/extensions-ui` and were visually inspected.

New HTTP suites: `profiles_http.py`, `capture_planning_http.py`, `intelligence_http.py`, `connectivity_http.py`. Adapter/OAuth tests: `connectivity_worker.py`, `calendar_authorization.py`. They are registered in `scripts/Invoke-QA.ps1`. Additional feature details and exact targeted results are in [profiles/family](profiles-family-packs.md), [local assistant/focus](local-assistant-focus.md) and [Connections](../docs/CONNECTIVITY.md).

Full source QA results are recorded separately in the runner's `tests/.tmp/qa-*/summary.json`. A successful source QA run does not establish fluent language quality, real external-provider acceptance, complete browser-profile isolation or installed Windows release behavior. No installer, deployment, release publication or personal-data update is included.
