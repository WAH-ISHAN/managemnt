# LifeOS compared with Jira

Audited 2026-10-30 against the local source and current official Atlassian documentation. **LifeOS does not contain all Jira options.** It has a useful local work tracker; several Jira concepts have smaller equivalents, while substantial configuration, collaboration and integration features are absent.

This comparison targets Jira Cloud work tracking, not Jira Service Management, Jira Align, Product Discovery, every Marketplace extension, or every plan-specific option. Jira capabilities vary by plan and space type; this is a practical feature audit, not a percentage of complete Jira parity. Atlassian's [feature overview](https://www.atlassian.com/software/jira/features) and [plan comparison](https://support.atlassian.com/jira-cloud-administration/docs/explore-jira-cloud-plans) were checked on the audit date.

**Implemented** means the stated local behavior exists, not identical Jira behavior. **Partial** means a related workflow exists with the stated gaps. **Missing** means no corresponding workflow was found in the module's schema, services, routes or views. Missing findings are source-inspection conclusions, not runtime tests of an absent feature.

## Practical follow-up

For personal university/business work, the remaining local gaps include a ranked backlog with sprint planning, custom fields, configurable transition rules, release merge/notes/lock behavior and richer reports. The new fixed type set, release records and WIP warnings are bounded local implementations. Team accounts/permissions, notifications, integrations and advanced planning require separate implementation and an explicit collaboration/service design. None is represented as implemented by adding the new fields.
