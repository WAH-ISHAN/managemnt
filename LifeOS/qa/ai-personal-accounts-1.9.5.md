# LifeOS 1.9.5 — personal AI connections

Implemented a dedicated **Settings → Connect my AI account** page using the installed OpenCode 2.2.5 official Console device OAuth method. Added connect/check/cancel/disconnect jobs, a temporary authenticated loopback server, native allowlisted browser opening, profile-isolated credential persistence and cancellation on lock/profile switching. Commercial chat requires the customer's own native connection; both PHP submission and the Windows worker enforce it. The normal conversation panel offers a connection link and keeps technical provider/model configuration out of the conversation.

No developer credentials, shared API keys, new AI runtime downloads or model weights were used. A shared-key OpenRouter prototype from the initial investigation was removed before deployment after the user clarified that customers should connect their own accounts. No website production source changed during this follow-up. Gmail/Google sign-in to the LifeOS website itself is not implemented here: that requires an Orean OAuth client registration, and it would still be a separate authorization from OpenCode.
