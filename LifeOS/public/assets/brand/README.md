# LifeOS brand artwork

Generated on 28 October 2026 using the built-in `image_gen` tool, with a transparent background. No external API or API key was used.

The flowing blue/indigo ribbon suggests an L and an opening path; the mint leaf suggests growth. A navy rounded tile gives the symbol contrast in both light and dark application surfaces.

- `lifeos-source.png`: unmodified generated 1254 × 1254 RGBA source.
- `lifeos-mark.png`: 256 × 256 display asset.
- `favicon-32.png`: 32 × 32 browser icon.
- `lifeos-64.png`, `lifeos-128.png`, `lifeos-512.png`: other display sizes.
- The repository's `icon.ico` contains 16, 24, 32, 48, 64, 128 and 256 pixel frames.

Run `python scripts/create-icon.py` from the project root to rebuild display assets and `icon.ico` from the saved source. Resizing preserves the generated alpha channel and does not require another image-generation call.

## Generation prompt

Use case: logo-brand.
Asset type: one finished production app icon for LifeOS, a personal Windows workspace for study, money, goals, planning and freedom.
Primary request: Design a beautiful premium minimal identity mark. A confident flowing ribbon subtly forms an L while opening upward into a graceful orbit, with one small leaf-like terminal suggesting personal growth and possibility. Elegant strong silhouette, three or fewer main visual elements, legible at 32 pixels.
Style: refined modern digital brand, precise smooth geometry, crisp edges with a restrained luminous blue-to-indigo ribbon and a tiny mint accent; subtle dimensional gradient only, no busy texture.
Composition: centered single symbol occupying around 68% of a deep navy rounded-square app tile. The rounded-square tile occupies around 90% of the square canvas with genuinely transparent outer margin and corners. Maintain strong light contrast for the symbol. Straight-on flat icon, no perspective.
Constraints: a single isolated completed square app icon, transparent outside the rounded-square navy tile. No words, no wordmark, no typography, no text, no mockup, no presentation board, no border, no drop shadow outside the tile, no watermark. Avoid robot, brain, stock sparkle, infinity sign and overly intricate paths. Make it calm, polished, distinctive and friendly.
